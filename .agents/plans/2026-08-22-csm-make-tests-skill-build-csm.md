## Design

Target behavior: `csm-make-tests` discovers as a registered, gated skill whose SKILL.md implements an 11-state test-generation pipeline (AUDIT→SCAN→CAPTURE→TRIAGE→APPROVE→VERIFY→AMPLIFY→DIFFERENTIAL→LAYER→PERF→OUTPUT) with MAINTAIN/AUDIT-first entry (audit existing tests+coverage before generating), never-auto-accept approval discipline, mutation-validated suites, Scientist-style differential guidance for refactor windows, profile-first performance playbook, and runtime-guarded residuals. Boundaries: writes only its own skill files + `.agents/tests/*` artifacts at run time; never invokes sibling skills; reads research findings as artifacts. Interfaces: Consumes repo@commit + optional change-surface scope + optional research finding; Produces executable tests/goldens + `.agents/tests/<yyyy-mm-dd>-<repo-slug>-tests-ledger.md` + verification report; Hands off verified suite to user or future csm-build; Never invokes all nine siblings. Data flow: research finding → reference files → state rules → user-repo execution. Key decisions: A1–A7 above.
