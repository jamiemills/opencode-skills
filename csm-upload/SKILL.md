---
name: csm-upload
description: upload screenshots, videos, and evidence files to a github pages demo site with a unique dated page name. requires gh cli and a github pages repo.

## Requirements

- **`gh` CLI** — must be installed and authenticated (`gh auth status`)
- **GitHub Pages repo** — a public repo with Pages enabled (defaults to `csm-browse-pages`)

## Configuration

Reads `~/.agents/csm-upload.json`:
```json
{"github": "jamiemills", "pagesRepo": "csm-browse-pages"}
```

- `github` — your GitHub username (auto-detected from `gh auth status` on first run)
- `pagesRepo` — the repo name to push to (must have GitHub Pages enabled on its default branch)

On first run or missing config, auto-detects from `gh auth status` and writes the file. Override with `--github <user>` and `--repo <name>` CLI flags.

## Usage

```bash
node $HOME/.config/opencode/skills/csm-upload/scripts/upload.mjs --label <name> [--desc <text>] [--github <user>] [--repo <name>] <file1> [file2...]
```

Creates `demo-YYYY-MM-DD-<name>/` on the pages site with an autogenerated `index.html` showing all uploaded images and videos.

## Examples

Upload a single screenshot:
```bash
node $HOME/.config/opencode/skills/csm-upload/scripts/upload.mjs --label nba-homepage --desc "NBA.com homepage" /tmp/screenshot.png
```

Upload a video and screenshot together:
```bash
node .../upload.mjs --label guardian-browse --desc "Guardian browse demo" /tmp/demo.webm /tmp/cover.png
```

The resulting page will be at:
`https://jamiemills.github.io/csm-browse-pages/demo-YYYY-MM-DD-<name>/`

## Typical workflow with csm-browse

```bash
# Capture a screenshot
node $HOME/.config/opencode/skills/csm-browse/scripts/browse.mjs screenshot --medium cover.jpg --session sid

# Upload it
node $HOME/.config/opencode/skills/csm-upload/scripts/upload.mjs --label nba-test /tmp/csm-browse/sid/artifacts/cover.jpg
```

The script handles git clone/pull, file copy, index.html generation, commit, and push automatically.
